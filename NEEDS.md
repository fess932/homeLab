## 2026-09-24 14:23 — Рекомендуемые настройки при установке

- `HOMEDECK_ALLOWED_HOSTS` — задать имена/IP, по которым открывается панель: это закрывает DNS rebinding для setup и публичной страницы. По умолчанию проверка выключена, чтобы первый запуск работал по любому адресу.
- `HOMEDECK_TRUSTED_PROXIES` — если панель за reverse proxy с HTTPS, иначе cookie будут без Secure.

## 2026-10-02 17:15 — Публикация расширения «новая вкладка» в Chrome Web Store

Расширение лежит в `extension/`, архив собирает `just extension` (`homedeck-newtab.zip`). Публикация идёт с твоего аккаунта Google, я её сделать не могу:

1. Зарегистрироваться разработчиком на https://chrome.google.com/webstore/devconsole (разовый взнос 5 USD).
2. «New item» → загрузить `homedeck-newtab.zip`.
3. Заполнить карточку: описание, минимум один снимок экрана 1280×800, категория; в разделе Privacy указать, что данные не собираются, назначение — подмена новой вкладки.
4. Visibility: «Unlisted», если расширение только для себя, — оно ставится по ссылке и не видно в поиске.
5. Отправить на проверку; обычно это занимает от пары дней.

Без публикации расширение работает через «Загрузить распакованное расширение» (см. `docs/operations.md`), но Chrome при запуске напоминает о режиме разработчика.

Не проверено глазами: приглушение фона на странице с настоящей картинкой (на тестовой странице фона не было) и само расширение в Chrome — его нужно один раз загрузить руками.
